# Production Workflow

## 1. Research lock
- Re-check current case status.
- Create claim ledger with source, date, procedural status, confidence, and approved narration wording.
- Flag contradictions across outlets instead of silently choosing the more dramatic number.

## 2. Script lock
Write the narration first. Every paragraph receives:
- purpose;
- source IDs;
- visual strategy;
- legal wording status;
- target duration.

## 3. Visual plan
For each beat choose one of:
- presenter/A-roll;
- archival material;
- document/source card;
- map/timeline;
- generic reenactment;
- motion graphic;
- atmospheric B-roll.

## 4. Asset acquisition/generation
Keep provenance next to each asset. Do not mix downloaded press photos, licensed assets, owned footage, and generated scenes without metadata.

## 5. Remotion assembly
Build reusable primitives before one-off scenes:
- chapter title;
- source card;
- quote card;
- evidence node;
- map pin/route;
- date/time card;
- reconstruction badge;
- lower-third;
- captions.

## 6. Sound
One narrator voice for the master. Use music as chapter-level tension architecture, not constant wallpaper. Add restrained room tone, impacts, paper/typing/camera/court ambience where editorially appropriate.

## 7. QA
- factual pass;
- legal-language pass;
- copyright/provenance pass;
- visual continuity pass;
- audio loudness pass;
- caption/RTL pass;
- mobile thumbnail/title test.

## 8. Render derivatives
- 16:9 long-form YouTube master;
- 9:16 30–60s hooks;
- optional 9:16 2–3 minute condensed narrative;
- thumbnail variants.
